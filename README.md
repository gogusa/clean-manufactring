# Clean Manufacturing, Inc. (Turnkey Beverage Co-Packing Platform)

High-speed contract beverage manufacturing, custom water formulation, and turnkey co-packing platform built with modern **React + Vite + Tailwind CSS**.

---

## 🚀 Key Features

1. **High-Speed Line Capabilities**:
   - **Line 1**: 1,200 BPM Aluminum Bottle & Can Line (Aseptic Cold Fill + Liquid Nitrogen Dosing).
   - **Line 2**: 600 BPM Flint Glass Luxury Line (Crown & ROOP Vacuum Capper).
   - **Line 3**: 1,000 BPM 100% Eco rPET Line (Integrated Blow Molding).
   - **Line 4**: Pilot R&D Micro-Batch Line (Hot Fill / Tunnel Pasteurization).

2. **Proprietary Water Chemistry & Formulation**:
   - Alkaline 8.8–9.5+ pH Titanium Electrolysis & Antioxidant ORP.
   - Molecular Hydrogen (H₂) Nanobubble Cavitation Infusion (1.6+ PPM).
   - 7-Stage Reverse Osmosis & UV Sub-Micron Polishing.
   - Natural Mountain Artesian Mineral Sourcing.
   - Custom Functional Electrolyte & Botanical Blending.

3. **Interactive 2D/3D Bottle & Packaging Studio**:
   - Live Canvas rendering of substrate shapes (Sleek Aluminum, Slim Can, Flint Glass, Eco rPET).
   - Real-time closure color, label finish (Matte, Gloss, Foil, Clear), and dynamic brand name printing onto the label.
   - One-click configuration export directly into the RFQ cost estimator.

4. **Dynamic Tiered RFQ Pricing Engine**:
   - Volume range slider (25,000 to 1,000,000+ units) with automatic tier discounts (up to 24% off).
   - Live per-unit pricing, total run estimate, pallet footprint math, and turnaround schedule.
   - Formal RFQ generation modal with printable/savable PDF spec sheet.

5. **Quality & Regulatory Benchmark Hub**:
   - SQF Level 3 (Score 99/100 Excellent).
   - 21 CFR Part 117 cGMP FDA Registered.
   - NSF/ANSI 60/61, OU Kosher Pareve, USDA Organic, Non-GMO Verified.
   - Real-time laboratory testing protocol grid (Spectrophotometry, Micro PCR clearance, H2 sensor telemetry).

---

## 🛠️ Technology Stack

- **Framework**: React 18 + Vite 6
- **Styling**: Tailwind CSS + PostCSS
- **Icons**: Lucide React
- **Graphics / Interactive**: HTML5 Canvas 2D + Canvas Confetti
- **Deployment**: Zero-configuration Vercel or Static Export (`dist/`)

---

## 💻 Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
